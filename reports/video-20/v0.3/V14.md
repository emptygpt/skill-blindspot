# Blindspot report: knowledge-explainer-skill

Map: video-long 0.2.1 (extends video 0.2.1)    Profile: none    Date: 2026-11-17

## Scope
- Turns a markdown/notes document into a scripted, silent 1280x720 slide-and-animation explainer video, rendered locally with Remotion; the agent writes `script.md` and, when needed, `custom/*.jsx`.
- Responsibility starts at the user's document and ends at a local mp4 the user opens.
- It does not involve filming, recording, audio, publishing, channel work or platform packaging.
- Missing file: SKILL.md:109 names `examples/my_topic.md`; it is a file the user is told to create, not a lost reference.

## Findings

### Needed
1. **The agent never inspects the rendered video; delivery check is duration, log and "let the user look"** [model+map+trace]
   Map node: asm.review-revision — source: O*NET 27-4032.00 "Review assembled films or edited videotapes on screens or monitors to determine if corrections are necessary"; asm.timecode-check — source: O*NET 27-4032.00 "Verify key numbers and time codes on materials"; script.revision
   Why: SKILL.md:50-55 "看时长是否符合预期 / 看渲染日志有无错误 / 用 open out/video.mp4 让用户自己看". Custom JSX is agent-written code, and a clean render log does not show clipped text, overlaps or an empty frame. grep terms on skill folder and repo root: still, frame, 预览, preview, screenshot, 截图 -> only Remotion API uses and cli.js total-seconds print; nothing inspects output or loops back to fix.
   Fix: Step 5 of the workflow ("检查输出"): add an agent-side check of sampled frames per scene and a return-to-step-2/3 rule when something is wrong, before handing the file over.
2. **No fact check of figures, formulas and simulated physics before delivery** [model+map]
   Map node: comp.fact-check — source: O*NET 27-3041.00 "Verify facts, dates, and statistics, using standard reference sources"; Video Production Course syllabus M14 "verifying AI-drafted facts"
   Why: The skill promotes numeric showcases (PaperFold milestones, double-pendulum equations) and has the agent author new ones (SKILL.md:36-46, 87-92). grep terms: fact, 核实, 校验, verify, 事实, 准确 -> only the CustomFunFact component's prop named `fact`; no instruction to check numbers against the source doc or a reference. Scope check: the content is generated inside the skill, so this is in scope.
   Fix: Step 2 or step 5: add a pass that checks every number, unit and formula in the script file and custom components against the source document or a reference, and flags what could not be confirmed.

### Worth considering
3. **No planning before the script: audience, core message, outline, length, opening** [model+map]
   Map nodes: topic.focus, topic.project-definition, script.story-message, script.outline, script.hook, script.audience-retention, long.open-close-key-moments — sources: YouTube for Creators Longform "Find your focus" and "Outline your video"; Video Production Course syllabus M1 "hooks", "Story and message"
   Why: Step 2 (SKILL.md:30-34) goes from reading the doc to choosing templates. grep: 受众, audience, 大纲, outline, 总时长, 摘要, 精简 -> no match in code or docs. Examples open with Title and the sample says "5 分钟讲明白" but renders 26 s.
   Fix: Between steps 1 and 2, add a short plan (who it is for, the one message, order of points, target length, how the first seconds hook).
4. **Output is silent: no narration, captions, music or sound design, and no word on silent viewing** [model+map]
   Map nodes: script.narration, sound.music-selection, sound.effects, sound.mix, captions.create, captions.silent-viewing — sources: ESCO "write voice-overs"; O*NET 27-4032.00 "Determine the specific audio and visual effects and music"; Video Production Course syllabus M13 "captions-on viewing"
   Why: grep: audio, 配音, 旁白, 字幕, subtitle, music -> only the template field `subtitle` and content text. If silence is deliberate, SKILL.md does not say so; a "讲解" video usually has a voice.
   Fix: Workflow step 2/4: either state that the output is intentionally silent and text must carry meaning, or add an optional narration/caption step.
5. **No scene breakdown mapping the source document to pages; long docs are not condensed** [model+map]
   Map nodes: script.shot-list-storyboard, script.ai-assisted, pre.breakdown — source: Video Production Course syllabus M14 "Plan and produce with AI"
   Why: SKILL.md:30-35 and 84-96 pick a template per content type, but no list of scenes tied to source sections and no check that the AI-drafted script keeps the source's meaning.
   Fix: Step 2: add a scene list linking each page to a source passage.

### Minor
6. **Only 1280x720 horizontal output; platform format is not discussed** [model+map]
   Map nodes: pre.aspect-ratio, pub.export — source: Video Production Course syllabus M13 "Format and aspect ratio"
   Why: width/height default in parser.js:73 and are settable in front matter; SKILL.md never mentions it. grep: 1080, 1920, 竖屏 -> no match.
   Fix: Mention the front matter options near step 4.
7. **Pacing guidance is limited to entrance timing** [model+map]
   Map node: edit.principles — source: Video: Digital Communication & Production Ch22 "Pace"
   Why: SKILL.md:78 only; per-page durations are chosen with no guidance.
   Fix: Add a rule of thumb for page duration versus text amount in step 2.
8. **Outro CTA with no room for platform end-screen elements** [model+map]
   Map node: long.end-screen-timing — source: YouTube Help "Add end screens to videos", "Best practices"
   Why: Outro template (SKILL.md:67) has title and cta only; the end-screen itself is added after the skill ends, so Minor.
   Fix: Optional note on leaving the last seconds empty.
9. **Custom files hardcode macOS fonts; no licensing or fallback note** [model+map]
   Map node: assets.font-licensing — source: Bilibili UP主创作手册 通用篇 (2020) "注意字体版权问题"
   Why: grep: 字体, font, license -> FONT constants in custom/*.jsx, MIT LICENSE for the repo only.
   Fix: Add a font note in "Custom 模板生成原则".

## Unsourced findings

- SKILL.md does not list prerequisites (ffmpeg, node) that README names; model only, no source checked.
