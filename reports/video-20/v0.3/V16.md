# Blindspot report: video-recap

Map: video-long 0.2.1 (extends video 0.2.1)    Profile: none    Date: 2026-11-17

## Scope
- Takes an existing video file (film, drama, documentary, explainer source) and produces a Chinese narrated recap or a source-sound cut as an MP4, with subtitles, optional canvas packaging, optional promo copy and an optional Jianying draft.
- Responsibility starts at the input file plus user context and ends at the rendered MP4, subtitles, cover.jpg and the work_dir records. It does not upload, publish, run a channel or read analytics.
- It does not involve filming, recording of people, lighting, camera work, account setup or monetisation. Sibling skill video-reference only breaks down finished videos for reference.
- Mixed lengths: 60-second shorts to 10-minute or longer explainers. Long-form nodes apply to the longer end.
