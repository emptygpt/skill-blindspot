# Blindspot report: make-short

Map: video-short 0.2.1 (extends video 0.2.1, 142 nodes)    Profile: none    Date: 2026-11-17

Note: `prepare` flagged `IDEAS.md`, `brand.md` and the per-short script file as missing; `IDEAS.md` and `brand.md` exist at the repository root and the script file is per-short, so they were resolved there. Sibling skills suggest-sfx and vidtsx-2d-generator were only searched, not audited.

## Scope
- Builds a fully-synthetic vertical short (1080x1920, about 40 s) from a topic: script + beats.json, Remotion TSX composition, phone-scale frame QA, render, ElevenLabs voice with word-exact captions, SFX audition mix, optional music bed.
- Responsibility starts at topic choice (from IDEAS.md) and ends at a mixed audition mp4 "awaiting the user's ear". It does not upload, write titles or descriptions, or track results.
- It involves no filming, stock, or third-party footage; crash rules are deferred to vidtsx-2d-generator and SFX taste to suggest-sfx.

## Findings

### Needed
None. Every candidate below is at least partly covered somewhere in the repository or happens after the skill's stop point.

### Worth considering
1. **No re-check of sync and file after the voice retimes everything** [model+trace+map]
   Map node: asm.review-revision, asm.platform-standards — source: see `sources` for both nodes (platform standards and review of the assembled cut).
   Why: grep `retim`, `re-render`, `ffprobe`, `duration`, `-t 42`. QA (lines 69-81) runs on estimated VO times; Stage 4 line 95 says only "re-render the composition (captions retimed) and mux", with `-t 42` hard-coded on line 97. Nothing says to look at frames again or probe the muxed file. The repo's own IDEAS.md line 83 records "THE RETIME LESSON": real word times left curves mid-growth at the spoken number and one animation had to be split in two. That lesson sits in the idea bank and is not an instruction in the skill, so this is kept below Needed.
   Fix: in Stage 4, add a step after gen_voice that re-reads the reveal cues against the new vo.gen.ts word times and re-runs the frame QA, and a final probe of the muxed file (length, audio present, ends with the voice) in place of the fixed `-t 42`.

2. **Voice, SFX and music licence is recorded but never checked** [model+map]
   Map node: assets.music-licensing, short.music-eligibility, comp.media-law-ethics — source: `sources` lists YouTube Help "Music eligibility for YouTube Shorts" and the course syllabus module on music licensing.
   Why: grep `licen`, `royalty`, `copyright`, `commercial`, `attribution`. Line 119 uses library beds; brand.md line 105 and catalog.json say each clip's `license` is recorded, and the licence text reads "commercial use per the generating account's" plan. Stage 4 and 6 never tell the agent to confirm the ElevenLabs plan allows commercial use of the voice, SFX and music, or to note a premade voice's terms.
   Fix: add one line to Stage 4 and Stage 6 to read the licence field and confirm the account plan before the clip counts as final.

3. **No synthetic-content disclosure note at hand-off** [model+map]
   Map node: comp.ai-disclosure, comp.staged-content — source: `sources` lists Douyin AI-content labelling rules and the course "Use AI responsibly" module.
   Why: grep `disclos`, `synthetic`, `AI-generated`, `altered`, `label`. Only the description (line 3) and line 8 call the video synthetic; no step produces a note for the person who uploads. Upload itself is outside scope, which is why this is not Needed. Short-7 in the repo is a fictional kids story.
   Fix: in "Done =" add a one-line hand-off note (synthetic voice, fictional scene) next to the final mp4.

4. **The designed seamless loop clashes with an unnoticed-loop rule** [map]
   Map node: short.honest-loop-payoff — source: Douyin rules centre, rule file on inducing engagement, "首尾内容完全一致，让人不易觉察循环播放" (from `sources`).
   Why: lines 40-41 and 46 require "last frame == frame 0 ... so it replays seamlessly". The node's source lists identical first and last content as a violation on Douyin. The skill targets YouTube Shorts, which this source does not cover, so this is the author's call.
   Fix: if the video may go to Douyin, add a line in the LOOP rule that the loop must be a visible payoff, or exclude the node in a profile for YouTube-only use.

5. **Fact-check has no method or record** [model+map]
   Map node: comp.fact-check, topic.subject-research, script.ai-assisted — source: course syllabus module on AI responsibility (from `sources`).
   Why: grep `fact`, `verif`, `source`. Lines 52 and 125 say "Facts must be verified" but not how, and the script-file contract (line 20) has no sources field. IDEAS.md shows the author does it per short.
   Fix: in Stage 1 add where to record each checked figure and its source in the script file's production notes.

8. **Trace: unused renders, no script gate, no final music pick** [trace]
   Map node: script.revision
   Why: the scale-1 render at line 80 is replaced by the post-voice re-render; no gate lets the user approve the script file before the composition is built; Stage 6 produces music auditions but no step picks a bed or produces a final, and "Done =" omits music.

9. **TTS pronunciation and caption language not checked** [model+map]
   Map node: captions.accuracy-accessibility, captions.translate
   Why: grep `pronounc`, `listen`, `mispronun`. Captions come from the same text as the TTS, but nothing listens for mispronounced terms or numbers; single language only.

    Map node: assets.font-licensing, assets.trademarks
    Why: grep `logo`, `trademark`, `brand-name`. brand.md fixes the fonts and media/library/logos holds logos; nothing in the skill says to check their terms. Short-8 sets the PayPal wordmark as styled text, so the author is aware of it.
