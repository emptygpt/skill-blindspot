The F# engine and compiled JS were not run; one engine source comment was read to learn about loudness normalisation, and is flagged as not part of the skill text.

## Scope
- Reads a code repository and makes a narrated, animated teaching video (or a progress video of changes since a commit) with chapters, code cards and recaps, rendered locally with a Kokoro voice, ffmpeg and headless Chrome.
- Starts at a repository and a goal sentence; ends at an MP4 (+ webm, poster, vtt captions, chapters vtt, optional pptx) and a REPORT.md. "Nothing is uploaded."
- Does not film people or publish. Not a general explainer: the subject is always a codebase.

### Worth considering
1. **No stated check of final audio level and no listening pass** [model+trace]
   Map node: sound.mix — source: Video Production Course Online (Self-Paced) syllabus, "M10 an audio mix"
   Why: SKILL.md never mentions loudness; the engine appears to normalise speech, but the skill does not tell the agent to confirm it or to listen to the final file. Narration audit reads text and timing; pronunciation errors are found only when "the user says a term sounded wrong".
2. **No opening hook rule and no end-screen/CTA** [model+map]
   Map node: script.hook, long.end-screen, long.end-screen-timing — source: Video Production Course Online (Self-Paced) syllabus, "M1 hooks"
   Why: The intro states the goal; the outro ties back to it. Neither is designed to win attention in the first seconds or to point a viewer onward.
3. **Licence of the code shown on screen and AI-voice labelling are not addressed** [model+map]
   Map node: assets.copyright-fair-use, assets.rights-acquisition, comp.ai-disclosure — source: YouTube for Creators: Helpful Resources, "Copyright"
   Why: Code is shown "verbatim" on cards. Only confidentiality is noted. A video with synthetic voice and AI-written script gets no label guidance.

   Map node: pack.title, pack.description-chapters, captions.translate, asm.platform-standards — source: YouTube Help: Thumbnail & title tips, "How to write titles"
   Why: Only the GitHub README case is specified.

   Nodes: assets.trademarks, sound.music-selection, sound.effects, captions.reach, captions.accuracy-accessibility, pub.one-to-many
   Why: no matching instruction in the skill; each is either outside what an author of this skill is likely to add, or a small addition. Exclude in a profile if intentional.
