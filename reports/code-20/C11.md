## Scope
- Decides whether to deprecate a system/API/feature, builds a production-proven replacement and actively migrates consumers before removing the old system.
- Includes announcements, guides, support, incremental consumer changes and production expand/backfill/contract schema changes; the called incremental skill supplies per-slice tests/builds/commits and its final DoD gate on that schema path.
- Ends at verified migrated consumers and removal of old code/tests/configuration/notices, or an independently deployed schema contract step with tested down paths.
- Does not design new authentication/cryptography/UI, acquire or audit dependencies, provision environments, instrument a new monitoring system or run a general release/maintenance programme; generic DoD pointers do not import those workflows.

### Needed
None. Consumer parity/regression checks, phased compatibility, tested down paths and per-slice verification supply partial safeguards for the in-scope gaps.

### Worth considering
1. **Prove backfill equivalence and recoverability before contraction** [model+map+trace]
   Map node: implementation.data-migration, testing.plan-strategy, testing.environment-and-data, version-control.revert, operations.admin-processes, agent.wrong-output — source: DORA, Database change management and Test data management <https://dora.dev/capabilities/>; O*NET 31.0, task 14638 <https://www.onetcenter.org/database.html>; GitHub Docs, Revert a pull request <https://docs.github.com/en/pull-requests>; The Twelve-Factor App, XII <https://12factor.net/>; OWASP LLM09 <https://genai.owasp.org/llm-top-10/>.
   Why: Expand/contract, throttling, consumer parity and tested down paths provide substantive safeguards. Resumability, concurrent dual-write reconciliation and restoration of values discarded during contraction are unspecified; reversing schema shape need not restore data.
   Fix: in Expand/Contract, add restart/concurrency cases, reconciliation evidence and rehearsed recovery or an explicitly approved irreversible boundary.
   Search check: `reconcil`, `idempotent`, `checkpoint`, `restore`, `dual-write` across skill/repository found the target's dual-write instructions; uncalled siblings/fixtures do not cover the remainder.

2. **Name removal authority and bound migration execution** [model+map+trace]
   Map node: review.owners-and-approval, agent.limit-agency, agent.human-oversight, agent.generated-code-execution, release.deploy — source: GitHub Docs, CODEOWNERS and branch protection <https://docs.github.com/en/pull-requests>; OWASP LLM05 and LLM06 <https://genai.owasp.org/llm-top-10/>; NIST AI 600-1, 2.7 <https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf>; DORA, Deployment automation <https://dora.dev/capabilities/>.
   Why: Zombie systems receive an owner and the schema path's final DoD requires human approval. Actual destructive steps and tooling still lack a named removal/data-owner decision, scoped execution identity and repeatable per-phase runbook.
   Fix: before cutover/cleanup, name decision owners, scope database/tool authority, inspect generated commands and record the migration deployment/recovery procedure.

3. **Treat migration evidence as data and minimise copied sensitive values** [model+map]
   Map node: agent.injected-instructions, agent.sensitive-data — source: OWASP LLM01 and LLM02 <https://genai.owasp.org/llm-top-10/>.
   Why: The agent consumes guides, consumer code and usage evidence without an instruction/data boundary or a minimisation rule for copied values. This depends on input trust/sensitivity, not a demand for new application authentication, privacy infrastructure or logging.
   Fix: at intake/reporting, distinguish supplied content from authority and limit/redact sensitive evidence.

### Minor
4. **Qualify zero usage with the observation window** [model+trace] (unsourced)
   Why: Metrics, logs and dependency analysis are required, but their observation window and dormant/offline-consumer treatment are unspecified. Zero traffic during an unrepresentative interval need not mean every consumer is migrated.
   Fix: at removal, record the representative window and unresolved dormant-consumer decisions.
